# GA Design Studio

Website for GA Design Studio, an architecture practice working across Dhule, Nashik, Mumbai and Pune.

*Creativity, Values and Freedom.*

## Brand

Logo concepts live in `brand/logo-concepts/`. Each concept has dark and light lockups, a standalone mark and a transparent version.

| Concept | Idea |
| --- | --- |
| 01 Plan Monogram | The G is a floor plan with a door swing. The A is a house section. |
| 02 Three Columns | Post and lintel. Creativity and Values hold the beam. Freedom breaks away. |
| 03 Section Cut | GA drawn as a building section, cut by a section line, with a north arrow inside the A. |

Palette: Blueprint Navy `#0A1628` · Drafting Ice `#DCE8F5` · Copper `#D08C5B` · Paper `#F4F1EA`
